# N.G.O-Website

Real-world client project — A modern, responsive website developed for **Parichay Nasha Mukti Kendra** (Rehabilitation Center & NGO), focused on presenting treatment programs, facilities, counselling, and emergency support services with a clean, professional, and user-friendly interface.

## Tech Stack
- **Frontend**: React, React Router DOM, React Icons
- **Build Tool**: Vite
- **Styling**: Modern CSS3 (Custom Design System with CSS Variables)

## Features
- 24/7 Helpline Header & WhatsApp Consultation Integration
- Detailed Services, Rehabilitation Process Timeline, Daily Routine Schedule, and FAQs
- Responsive Layout (Mobile, Tablet, Desktop)
- Clean, Healthcare & Rehabilitation Aesthetic
